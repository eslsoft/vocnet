# 项目介绍

## 💡 vocnet 是什么

**vocnet** 是一个开源的词汇网络管理平台，致力于解决英语学习者的核心痛点：**词汇数据分散，无法统一管理**。

### 核心理念

市面上有很多优秀的英语学习 APP（阅读类、视频类、游戏化学习等），但用户的词汇数据分散在各个平台：

- 在扇贝学了 500 个词
- 在百词斩学了 300 个词
- 在 Anki 导入了 200 个词
- 在阅读 APP 收藏了 150 个生词

**结果**：

- ❌ 换 APP 需要重新测试水平，浪费时间
- ❌ 没有一个地方能看到完整的学习数据
- ❌ 词汇掌握度无法跨应用追踪

**vocnet 的解决方案**：

- ✅ 成为用户全生命周期的词汇数据中心
- ✅ 无论在哪个 APP 学习，数据都存在 vocnet
- ✅ 基于 FSRS 算法提供科学的复习系统
- ✅ 开放 API，让第三方 APP 轻松接入

## 🎯 vocnet 定位

### 对终端用户

vocnet 是一个**词汇学习和复习平台**：

| 功能          | 说明                             |
| ------------- | -------------------------------- |
| 📚 词汇管理   | 管理你在所有 APP 中学习的词汇    |
| 🧠 科学复习   | 基于 FSRS 算法生成个性化复习计划 |
| 📊 掌握度跟踪 | 听说读写分项跟踪（0-5 级）       |
| 🔗 词汇网络   | 同义词、派生词、助记联想         |
| 📱 跨设备同步 | Web / 移动端随时复习             |

### 对开发者

vocnet 是一个**词汇数据管理基础设施**：

| 优势          | 说明                                  |
| ------------- | ------------------------------------- |
| 🛠️ 开箱即用   | 词汇存储、掌握度管理、FSRS 算法       |
| 🌐 标准 API   | ConnectRPC，自动生成全平台 SDK        |
| 📦 SDK 支持   | Go / TypeScript / Swift / Kotlin      |
| 🚀 专注差异化 | 把词汇管理交给 vocnet，你专注内容体验 |

**典型场景**：

- 你做阅读 APP → 用户标记生词存到 vocnet → vocnet 负责复习
- 你做视频 APP → 字幕生词存到 vocnet → 掌握度跨 APP 同步
- 你做 Chrome 扩展 → 划词收藏到 vocnet → 统一复习入口

## 🌟 与传统背单词 APP 的区别

| 维度            | 传统 APP（扇贝、百词斩等） | vocnet                 |
| --------------- | -------------------------- | ---------------------- |
| **数据归属**    | 锁定在单一 APP             | 跨 APP 的数据中心      |
| **换 APP 成本** | 需要重新测试水平           | 掌握度数据跟随用户     |
| **复习算法**    | 各自实现（质量参差）       | 统一的 FSRS 科学算法   |
| **开源透明**    | 闭源，数据不透明           | 开源，数据自主权       |
| **生态**        | 封闭                       | 开放 API，第三方可接入 |
| **专注度**      | 大而全但不专精             | 专注词汇管理           |

**核心差异化**：

1. **全生命周期词汇管理** — 从首次收藏到完全掌握，持续追踪
2. **跨 APP 数据中心** — 无论在哪学习，数据统一管理
3. **开放 API 生态** — 赋能开发者，而非竞争
4. **数据自主权** — 开源、可导出、可自建

## 🔧 我们做什么 vs 不做什么

### ✅ vocnet 专注做的

- **词汇数据管理**：收藏、去重、分类、标签
- **掌握度跟踪**：听说读写分项、动态更新
- **FSRS 复习算法**：科学的间隔重复调度
- **Flashcards 系统**：生成复习卡片、提交结果
- **词汇关系网络**：同义、反义、派生、助记
- **开放 API**：ConnectRPC，自动生成全平台 SDK
- **用户客户端**：Web / 移动端，用户复习单词

### ❌ vocnet 不做的（留给第三方 APP）

- **阅读文章**：第三方 APP 提供内容和阅读体验
- **视频播放器**：字幕高亮、互动由视频 APP 负责
- **网页生词高亮**：Chrome 扩展等工具实现
- **游戏化学习**：如多邻国式的关卡、积分、排行榜
- **课程内容**：系统化的学习路径和教材
- **AI 对话教学**：智能对话、作文批改等高级功能

**设计哲学**：

> vocnet 是"词汇管理的基础设施"，不与第三方 APP 竞争内容和体验，而是赋能开发者。

## 🌐 生态策略

### 我们服务谁？

- ✅ **个人开发者**：正在做或想做英语学习工具
- ✅ **创业团队**：需要快速验证 MVP
- ✅ **开源项目**：如 Anki 插件、浏览器扩展
- ✅ **企业/教育机构**：需要私有化部署

### 我们不对接谁？

- ❌ **大型成熟 APP**（扇贝、百词斩等）：他们是竞品，有自己的生态

**核心理念**：

> 围绕"未来"构建生态，服务新一代学习工具开发者。

## 🚀 技术特性

- **Clean Architecture**：分层清晰，易于扩展
- **ConnectRPC**：兼容 HTTP/1.1、HTTP/2、HTTP/3，自动生成全平台 SDK
- **SQLite / PostgreSQL**：灵活的数据库选择
- **FSRS 算法**：基于最新记忆科学
- **OAuth2 认证**：标准化的第三方集成
- **容器化部署**：Docker 开箱即用
