# 项目介绍

## Vocnet 是什么

**Vocnet** 是一个开源的词汇网络管理平台，致力于解决英语学习者的核心痛点：**词汇数据分散，无法统一管理**。

### 核心理念

市面上有很多优秀的英语学习应用（阅读类、视频类、游戏化学习等），但用户的词汇数据分散在各个平台：

- 在扇贝学了 500 个词
- 在百词斩学了 300 个词
- 在 Anki 导入了 200 个词
- 在阅读应用收藏了 150 个生词

**问题**：

- 换应用需要重新测试水平，浪费时间
- 没有一个地方能看到完整的学习数据
- 词汇掌握度无法跨应用追踪

**Vocnet 的解决方案**：

!!! success "核心价值"
    - 成为用户全生命周期的词汇数据中心
    - 无论在哪个应用学习，数据都统一存储在 Vocnet
    - 基于 FSRS 算法提供科学的复习系统
    - 开放 API，让第三方应用轻松接入

---

## Vocnet 定位

### 对终端用户

Vocnet 是一个**词汇学习和复习平台**：

| 功能 | 说明 |
|------|------|
| 词汇管理 | 管理你在所有应用中学习的词汇 |
| 科学复习 | 基于 FSRS 算法生成个性化复习计划 |
| 掌握度跟踪 | 听说读写分项跟踪（0-5 级） |
| 词汇网络 | 同义词、派生词、助记联想 |
| 跨设备同步 | Web / 移动端随时复习 |

### 对开发者

Vocnet 是一个**词汇数据管理基础设施**：

| 优势 | 说明 |
|------|------|
| 开箱即用 | 词汇存储、掌握度管理、FSRS 算法 |
| 标准 API | ConnectRPC，自动生成全平台 SDK |
| SDK 支持 | Go / TypeScript / Swift / Kotlin |
| 专注差异化 | 把词汇管理交给 Vocnet，你专注内容体验 |

**典型集成场景**：

- 阅读应用 → 用户标记生词存到 Vocnet → Vocnet 负责复习
- 视频应用 → 字幕生词存到 Vocnet → 掌握度跨应用同步
- 浏览器扩展 → 划词收藏到 Vocnet → 统一复习入口

## 设计哲学

### Vocnet 专注做的

Vocnet 专注于词汇管理的核心功能：

- **词汇数据管理** - 收藏、去重、分类、标签
- **掌握度跟踪** - 听说读写分项、动态更新
- **FSRS 复习算法** - 科学的间隔重复调度
- **Flashcards 系统** - 生成复习卡片、提交结果
- **词汇关系网络** - 同义、反义、派生、助记
- **开放 API** - ConnectRPC，自动生成全平台 SDK
- **用户客户端** - Web / 移动端，用户复习单词

### Vocnet 不做的（留给第三方应用）

为了保持专注，以下功能由第三方应用提供：

- **阅读文章** - 第三方应用提供内容和阅读体验
- **视频播放器** - 字幕高亮、互动由视频应用负责
- **网页生词高亮** - Chrome 扩展等工具实现
- **游戏化学习** - 如多邻国式的关卡、积分、排行榜
- **课程内容** - 系统化的学习路径和教材
- **AI 对话教学** - 智能对话、作文批改等高级功能

!!! abstract "核心理念"
    Vocnet 是"词汇管理的基础设施"，不与第三方应用竞争内容和体验，而是赋能开发者。

---

## 为什么选择 Vocnet

### 核心差异化

1. **全生命周期词汇管理** - 从首次收藏到完全掌握，持续追踪
2. **跨应用数据中心** - 无论在哪学习，数据统一管理
3. **开放 API 生态** - 赋能开发者，而非竞争
4. **数据自主权** - 开源、可导出、可自建
