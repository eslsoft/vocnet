# 快速开始 - 用户指南

> 5 分钟了解如何使用 Vocnet 管理和复习词汇

本指南面向**语言学习者**，帮助你快速开始使用 Vocnet 进行词汇学习和复习。

---

## 前置条件

开始之前，你需要：

- **Vocnet 账号**
  - 官方实例：访问 [https://vocnet.apps.tftt.cc](https://vocnet.apps.tftt.cc) 注册（计划中）
  - 自建实例：如果你的组织/个人部署了 Vocnet，请获取访问地址
- 浏览器（推荐 Chrome / Firefox / Safari 最新版本）

!!! tip "自建部署"

如果你想自己部署 Vocnet，请查看 [自建部署指南](../self-hosting/installation.md)

---

## 第一步：创建账号并登录

### 注册账号

1. 访问 Vocnet 实例地址
2. 点击「注册」按钮
3. 填写邮箱和密码
4. 验证邮箱（如果需要）
5. 完成注册，自动登录

### 登录已有账号

如果你已经有账号，直接使用邮箱和密码登录即可。

!!! info "OAuth2 登录"

部分 Vocnet 实例可能支持第三方登录（Google、GitHub 等），具体取决于实例配置。

---

## 第二步：收藏第一个单词

登录后，你可以开始添加词汇到你的个人词库。

### 手动添加词汇

1. 在首页或词汇页面，点击「添加单词」按钮
2. 输入单词（例如：apple）
3. 系统会自动查询词典，显示：
   - 音标和发音
   - 词性和释义
   - 例句
4. 设置初始掌握程度（0-5 级）：
   - **0 级** - 完全不认识
   - **1-2 级** - 有印象但不熟悉
   - **3-4 级** - 基本掌握
   - **5 级** - 完全掌握
5. （可选）添加个人笔记或标签
6. 点击「收藏」

### 掌握度分项

Vocnet 支持按技能分项跟踪掌握度：

| 技能     | 说明         |
| -------- | ------------ |
| **听力** | 能听懂该词   |
| **阅读** | 能认出该词   |
| **拼写** | 能正确拼写   |
| **口语** | 能流利说出   |
| **综合** | 整体掌握程度 |

!!! tip "建议"

刚开始不用太纠结分项评分，先从综合掌握度开始，随着学习深入再细化。

---

## 第三步：开始复习

Vocnet 使用 FSRS 算法自动安排复习计划。

### 查看今日复习

1. 进入「复习」页面
2. 系统会显示今日需要复习的单词数量
3. 点击「开始复习」

### 完成 Flashcard

Vocnet 提供多种复习题型：

- **选择题** - 选择正确的释义
- **填空题** - 根据释义填写单词
- **拼写题** - 听音拼写
- **排序题** - 句子重组
- **配对题** - 单词与释义配对
- **口语题** - 跟读发音（需要麦克风）

### 提交答案

1. 完成每道题目后，点击「提交」
2. 系统会显示正确答案和解析
3. 根据你的答题情况，自动调整下次复习时间：
   - 答对 → 延长复习间隔
   - 答错 → 缩短复习间隔
4. 继续下一题，直到完成今日计划

!!! success "复习完成"

完成今日复习后，你可以：

    - 查看今日统计（复习数量、正确率、用时）
    - 查看学习日历（连续打卡天数）
    - 添加新词汇

---

## 第四步：连接第三方应用（可选）

Vocnet 的强大之处在于**跨应用的数据同步**。你可以将其他学习应用连接到 Vocnet。

### 授权流程

1. 在第三方应用中找到「连接 Vocnet」功能
2. 点击后会跳转到 Vocnet 授权页面
3. 查看应用请求的权限（例如：读取词汇、添加词汇）
4. 确认授权
5. 自动返回第三方应用，连接成功

### 数据同步

授权后：

- 第三方应用中收藏的单词会自动同步到 Vocnet
- 在 Vocnet 中的复习记录会更新掌握度
- 掌握度变化会同步回第三方应用

!!! example "典型场景"

- 在阅读 APP 中标记生词 → 自动添加到 Vocnet
- 在 Vocnet 中复习并掌握 → 阅读 APP 中该词标记为「已掌握」
- 所有数据统一管理，无需在多个应用中重复学习

### 查看已授权应用

1. 进入「设置」→「应用授权」
2. 查看已连接的第三方应用
3. 可以随时撤销授权

## 进阶功能

### 词本管理

Vocnet 支持将词汇组织到不同的词本中：

- **系统词本** - 如「IELTS 核心词汇」「四级词汇」等
- **自建词本** - 创建自己的主题词本（如「旅游英语」「技术术语」）

!!! tip "使用词本"

1. 进入「词本」页面
2. 点击「创建词本」
3. 将单词添加到词本
4. 可以针对特定词本创建复习计划

### 学习统计

查看你的学习数据：

- **总词汇量** - 已收藏的单词总数
- **掌握度分布** - 各级别单词数量
- **复习日历** - 学习热力图
- **今日统计** - 复习数量、新增单词、学习时长

## 常见问题

### 如何修改单词的掌握度？

进入单词详情页，可以手动调整掌握度评分。

### 可以导出我的词汇数据吗？

可以。进入「设置」→「数据导出」，支持导出为 JSON 或 CSV 格式。

### 复习算法是怎样的？

Vocnet 使用 FSRS（Free Spaced Repetition Scheduler）算法，这是一种科学的间隔重复算法。详见：[FSRS 算法](../concepts/fsrs-algorithm.md)

### 如何删除单词？

进入单词详情页，点击「取消收藏」即可从你的词库中移除。

### 支持移动端吗？

目前提供 Web 版本，移动端 APP 正在开发中。你可以在手机浏览器中访问 Web 版。
