# 安装指南

本页主要面向**终端用户**，介绍如何快速开始使用 vocnet 官方托管服务或桌面 / 客户端应用。如果你是想在本地或服务器上部署 vocnet，请参考自建部署文档：[`自建部署安装指南`](../self-hosting/installation.md)。

## 使用官方托管服务（推荐）

1. 访问官网（规划中）：`https://vocnet.apps.tftt.cc`
2. 使用 GitHub / 邮箱注册账号
3. 完成邮箱验证并登录
4. 在「词本」中创建或导入词本，开始学习

更多使用说明可查看：[新用户指南](quickstart-users.md)。

## 使用第三方客户端

部分第三方软件可能内置对 vocnet 的支持，一般需要：

1. 在客户端中选择「连接 vocnet」
2. 浏览器中完成 OAuth2 授权
3. 回到客户端开始同步和学习

如果你正在开发自己的客户端，请参考开发者文档中的：[集成指南](../developers/integration-guide.md)。
