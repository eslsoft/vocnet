# 主动词汇与被动词汇（方案，2026-11-14）

## 1. 背景

学习者需要知道一个词要掌握到什么程度：有的词要会说、会写，有的词听到、读到能懂就够了。语言学里这叫**产出性词汇**（productive vocabulary，也叫主动词汇：说和写时能用出来）和**接受性词汇**（receptive vocabulary，也叫被动词汇：听和读时能理解），见 Nation《Learning Vocabulary in Another Language》。听、说、读、写四项是这两类再按“口头 / 书面”拆分：

|  | 口头 | 书面 |
|---|---|---|
| 接受性（理解） | 听 | 读 |
| 产出性（使用） | 说 | 写 |

现在没有这类数据。相关的只有：按“词 + 词性”的 CEFR 等级（`lemma_cefr`，CEFR-J 与 Octanove，9,988 条）、词频（wordfreq）、义项的 common / extra 分级、义项的语域与地域标签。它们都不能直接回答“这个词要不要会用”。

## 2. 目标

- 每个词条按词性，分两档标出它是否属于产出性词汇：**母语者**一档，**高级二语学习者**一档。
- 单词词条和短语词条都覆盖。
- 听说读写的细分由服务端算好返回，不额外产出。
- 和其他事实一样走产出、审核、发布，可追溯、可纠正。

## 3. 数据模型

### 3.1 新事实类型 `productive_use`

名字取自 productive vocabulary。不用 `productive`：它与词法的能产性（morphological productivity）撞名；不用 `vocabulary`：整个项目都是词汇，看不出说的是哪一面。

| 项 | 内容 |
|---|---|
| 挂在 | 词条（entry） |
| 数量 | 每个词性一条：新增数量规则 `per_pos`（与 `per_language` 同理），格（`slot`）就是词性，沿用现有的唯一索引 |
| 内容 | `{ pos, native, learner }`，`native` 和 `learner` 是布尔值：`true` 为主动（产出性），`false` 为被动（只需理解） |
| 内容键 | `pos`、`native`、`learner` |
| 写入规则 | `native` 为 `false` 时 `learner` 必须也是 `false`（学习者的主动词汇是母语者主动词汇的一部分），否则 `400`（格式规则）；`pos` 必须是该词条某个 common 义项的词性，否则 `422 invalid_reference` |
| 审核 | Jev 每档一问，按取值选问题（见 3.3），两问都 ≥ 0.8 即通过；否则交审核模型判断整条 |

- 只对 common 义项生效。**extra 义项（罕见、专业、过时）两档一律视为被动**，不单独标，也不占格。词条有几个 common 义项的词性，就有几个格。
- 短语词条的义项通常只有一个词性，所以一般只有一条。
- 两档放在同一条事实里一起产出、一起审核，便于拦住前后矛盾的判断。

### 3.2 判断标准（2026-11-14 确认）

**母语者（`native`）**

- 主动：母语者在日常说话或写作中会自己用出这个词（这个词性），包括书面正式词和本地区的口语、俚语。
- 被动：母语者听到或读到能懂，但自己很少说出或写出，例如古旧词、文学用语、领域之外的专业术语。

**高级二语学习者（`learner`）**：CEFR C1 左右，能用英语学习、工作和日常交流（约相当于雅思 7 分以上）。

- 主动：这样的学习者需要自己会用，包括常用词和日常事物的名称、学术与职场词汇、常用短语动词、常用习语和固定短语（spill the beans、by the way 这类常见习语算主动）。
- 被动：认识即可，包括俚语、带调侃或强烈口语化的习语、只在某一地区通用的口语词（英式、美式同等对待：gobsmacked、knackered 是被动，truck、sidewalk 这类地区标准用法仍是主动），以及母语者也只是被动的词。

给模型和审核的例子（对齐用，正式规则写进 `fact-kinds.ts`）：

| 词 | 母语者 | 高级二语学习者 | 说明 |
|---|---|---|---|
| house（n.）、eat（v.）、give up | 主动 | 主动 | 基础词与常用短语动词 |
| nevertheless（adv.） | 主动 | 主动 | 书面语常用，写作要会用 |
| present（v. 呈现、颁发） | 主动 | 主动 | 偏正式，学术与职场常用 |
| a piece of cake | 主动 | 主动 | 口语常用习语 |
| kick the bucket | 主动 | 被动 | 习语带调侃，学习者认识即可 |
| gobsmacked、knackered | 主动 | 被动 | 英式口语俚语 |
| henceforth、ere、betwixt | 被动 | 被动 | 古旧或文学用语 |
| red shift、marshalling yard | 被动 | 被动 | 领域外的专业术语 |

参考信息一并给到产出方与审核方：词频、该词性 common 义项的释义与语域、地域标签。CEFR 等级只作背景，不作标准。

### 3.3 Jev 的问题（2026-11-14 试跑定稿）

每档按取值选一个专门的问题，不用一正一反的对称问法：试跑中“认识就够吗”几乎对所有词都答“是”，0.8 下有 12/113 条错误的“学习者被动”会被放行。问题里的例词避开审核的例子。

| 取值 | 问题要点 |
|---|---|
| 母语者 主动 | 母语者自己会说、会写这个词吗（列出算主动的几类：日常词、书面正式词、本地区口语） |
| 母语者 被动 | 它是母语者能懂但很少自己用的古旧、文学用语或领域外术语吗 |
| 学习者 主动 | 它是 C1 学习者该在自己的说写中用的普通词汇吗（列出主动的几类与被动的几类） |
| 学习者 被动 | 它是俚语、调侃或强烈口语化的习语、单一地区的口语词、古旧或文学用语、领域外术语吗 |

试跑（Jev 1.14.0，180 个词：80 个构造例子与 100 个库内随机词条，人工标注，模棱两可的 11 个不计）：

| 阈值 | 母语者档 Jev 判定 | 学习者档 Jev 判定 | 错误判断被放行 | 两档都由 Jev 判定（库内样本） |
|---|---|---|---|---|
| 0.8（采用） | 146/169 | 143/169 | 0 | 65/89（73%） |
| 0.75 | 157/169 | 154/169 | 0 | 74/89（83%） |

- 速度：10 并发，180 次调用 2.3 秒，p50 98ms，一万条事实的 Jev 审核几分钟内完成。
- 约 27% 交审核模型，按一万条算约 2,700 次。
- 库内随机词条 93%（83/89）是两档都主动：现有词表来自 CEFR，几乎不收俚语和古旧词。这一万条大多是确认默认值，词表扩充后这一项才会大量区分。

### 3.4 听说读写的细分（服务端算好后返回，不产出）

两档各自由主动 / 被动与该词性 common 义项的语域标签算出，作为派生字段返回，不存成事实。语域取现有 `Register` 的值：

- 偏口语：该词性的 common 义项全部标了 informal、slang、taboo 或 offensive。
- 偏书面：该词性的 common 义项全部标了 formal 或 literary。
- 其余（有未标语域的义项、标签混杂、或只有 dated、technical、ironic）为无明显倾向。

| 取值 | 偏口语 | 偏书面 | 无明显倾向 |
|---|---|---|---|
| 主动 | 听、说 | 读、写 | 听、说、读、写 |
| 被动 | 听 | 读 | 听、读 |

## 4. 工作项

- 新工作类型 `productive_use`，放在第 4 阶段（用法），是词条一级的规则（与发音按口音开格同理），缺哪个词性就列出哪个词性；依赖义项清单已发布。
- 计入完成度：每个词条的每个 common 词性都要有一条。现有已完成的词条会因此重新打开，这是预期的。
- 短语词条的四种类型（phrasal_verb、compound、idiom、fixed_phrase）都开这个格。
- 单词词条先做：8,705 个词条，约一万条事实。
- 短语词条跟随短语生产一起做，不单独再跑。

## 5. 公开接口

放在按词性分组的 `Meaning` 上，与该词性的 `cefr` 并列：

```json
"meanings": [
  {
    "pos": "verb",
    "cefr": "B1",
    "productive_use": { "native": true, "learner": false },
    "skills": { "native": ["listen", "speak", "read", "write"], "learner": ["listen", "read"] }
  }
]
```

- `productive_use` 两档各为布尔值，界面上显示为“主动 / 被动”。
- `skills` 是服务端按 3.4 算好的细分，取值为 `listen`、`speak`、`read`、`write` 的子集。
- 该词性还没有已发布的 `productive_use` 时，两个字段都为 `null`。
- 只有 extra 义项的词性两档默认被动，返回 `{ native: false, learner: false }`，`skills` 按被动、无明显倾向算。

## 6. 实现范围

1. 服务端：`shared/facts.ts` 增加数据格式；`server/domain/fact-kinds.ts` 登记类型（主体、`per_pos` 数量规则、内容键、写入规则、3.3 的审核问题）；工作项规则与阶段；完成度计入；公开视图与接口；同步 `docs/design.md`、`spec/*.feature` 与测试，`pnpm verify` 通过。
2. 服务端分类（2026-11-14 改定）：这是在已有义项上做选择，不产生新内容，所以不交给生产端。定时任务以 `system:classifier` 身份领取 `productive_use` 工作项，每档用 Jev 正反两问，取分数高的一边；所选分数都 ≥ 0.8 时直接发布（审核记为 `jev`），否则由审核模型直接选择（记为 `jev+llm`）。新词条、义项变化后打开的格，下一次定时任务自动分类。先前用生产端 LLM 智能体做，每批 10 个词约 20 轮对话，成本过高。
3. 存量：不需要迁移，新增的格会在下一次重算时为每个词条打开，由 worker 产出。
4. 上线后先抽样审一批（如 A1 和 C1 各 100 条），确认两档判断稳定再放量。

## 7. 已确认（2026-11-14）

1. 分两档：母语者、高级二语学习者；高级二语学习者按 CEFR C1 定。
2. 界面叫“主动 / 被动”；事实类型与接口字段叫 `productive_use`，两档为布尔值。
3. 接口两档都返回，并各自带算好的听说读写细分。
4. Jev 阈值 0.8，按取值选问题（3.3）。

## 8. 不在本次范围

- 更多档位（例如中级学习者 B1–B2）。
- 按义项单独标主动 / 被动（extra 义项统一视为被动，common 义项跟随词条的词性）。
- 考试词表标签（之前已决定暂缓）。
- 语法事实（仍暂停）。
