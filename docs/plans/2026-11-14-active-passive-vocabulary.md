# 主动词汇与被动词汇（方案，2026-11-14）

## 1. 背景

学习者需要知道一个词要掌握到什么程度：有的词要会说、会写，有的词听到、读到能懂就够了。专业上这叫**主动词汇**（productive vocabulary：说和写时能用出来）和**被动词汇**（receptive vocabulary：听和读时能理解）。听、说、读、写四项是这两类再按“口头 / 书面”拆分：

|  | 口头 | 书面 |
|---|---|---|
| 被动（理解） | 听 | 读 |
| 主动（使用） | 说 | 写 |

现在没有这类数据。相关的只有：按“词 + 词性”的 CEFR 等级（`lemma_cefr`，CEFR-J 与 Octanove，9,988 条）、词频（wordfreq）、义项的 common / extra 分级、义项的语域与地域标签。它们都不能直接回答“这个词要不要会用”。

## 2. 目标

- 每个词条按词性标出它是主动词汇还是被动词汇。
- 单词词条和短语词条都覆盖。
- 听说读写的细分由已有数据推出，不额外产出。
- 和其他事实一样走产出、审核、发布，可追溯、可纠正。

## 3. 数据模型

### 3.1 新事实类型 `vocabulary`

| 项 | 内容 |
|---|---|
| 挂在 | 词条（entry） |
| 数量 | 每个词性一条（与翻译“每种语言一条”同理，按词性占一个格） |
| 内容 | `{ pos, use }`，`use` 为 `active`（主动）或 `passive`（被动） |
| 内容键 | `pos` 与 `use` |
| 审核 | Jev 判断，过阈值即定；不过的交审核模型 |

- `pos` 必须是该词条某个 **common** 义项的词性；词条有几个 common 义项的词性，就有几个格。
- 只对 common 义项生效。**extra 义项（罕见、专业、过时）一律视为被动词汇**，不单独标，也不占格。
- 短语词条的义项通常只有一个词性，所以一般只有一条。

### 3.2 判断标准

以“达到这个词所在等级的普通学习者”为参照（单词用 CEFR 等级；短语和没有等级的词，按其主词等级与词频判断）：

- **主动**：这一水平的学习者在日常说话或写作中需要自己用出这个词（这个词性）。
- **被动**：这一水平的学习者听到或读到时需要能懂，但很少需要自己说出或写出。

给模型和审核的例子（对齐用，正式规则写进 `fact-kinds.ts`）：

| 词 | 判断 | 说明 |
|---|---|---|
| house（n.）、eat（v.）、happy（adj.） | 主动 | 基础词，必须会用 |
| present（n. 礼物） | 主动 | 日常常用 |
| present（v. 呈现、颁发） | 被动 | 偏正式，多数学习者认识即可 |
| nevertheless（adv.） | 被动 | 等级不高但主要出现在书面语，学习者多数只需读懂 |
| give up、look for、turn on | 主动 | 高频短语动词 |
| post office、bus stop | 主动 | 日常事物名称 |
| kick the bucket、a piece of cake | 被动 | 习语大多认识即可 |
| marshalling yard、red shift | 被动 | 专业复合词 |

参考信息一并给到产出方与审核方：CEFR 等级、词频、该词性 common 义项的释义与语域标签。

### 3.3 听说读写的细分（推导，不产出）

在公开数据里，由 `use` 与语域标签推出细分提示，作为派生字段返回，不存成事实：

| `use` | 语域偏口语（informal、slang、spoken） | 语域偏书面（formal、literary） | 无明显倾向 |
|---|---|---|---|
| active | 会听、会说 | 会读、会写 | 听说读写都会 |
| passive | 能听懂 | 能读懂 | 能听懂、能读懂 |

## 4. 工作项

- 新工作类型 `vocabulary`，放在第 4 阶段（用法），依赖义项清单已发布（要知道有哪些 common 义项的词性）。
- 属于必做的格（core）：每个词条的每个 common 词性都要有一条，计入完成度。
- 单词词条先做：8,705 个词条，约一万条事实。
- 短语词条跟随短语生产一起做，不单独再跑。

## 5. 公开接口

- 词条按词性返回 `vocabulary: [{ pos, use, modes }]`，`modes` 是 3.3 推出的听说读写提示。
- extra 义项不返回此项（默认被动）。

## 6. 实现范围

1. 服务端：`shared/facts.ts` 增加数据格式；`server/domain/fact-kinds.ts` 登记类型（主体、数量、内容键、审核规则）；工作项规则与阶段；完成度计入；公开视图与接口；同步 `docs/design.md`、`spec/*.feature` 与测试，`pnpm verify` 通过。
2. 生产端：新增 `vocabulary` 工作模板，给出与审核相同的判断标准和例子。
3. 存量：不需要迁移，新增的格会在下一次重算时为每个词条打开，由 worker 产出。
4. 上线后先抽样审一批（如 A1 和 C1 各 100 条），确认判断稳定再放量。

## 7. 待确认

1. **参照的学习者**：按“达到该词等级的学习者”判断（本方案），还是统一按一个目标水平（比如 B2）判断？前者每个等级内部区分主被动；后者更像“要达到 B2 需要主动会用哪些词”。
2. **对外叫法**：接口字段用 `active` / `passive`，界面上叫“主动 / 被动”，还是“会用 / 认识”？
3. **细分提示**：3.3 的听说读写提示是否需要，还是只要主动 / 被动两档？

## 8. 不在本次范围

- 按义项单独标主动 / 被动（extra 义项统一视为被动，common 义项跟随词条的词性）。
- 考试词表标签（之前已决定暂缓）。
- 语法事实（仍暂停）。
