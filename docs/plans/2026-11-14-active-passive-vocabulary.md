# 主动词汇与被动词汇（方案，2026-11-14）

## 1. 背景

学习者需要知道一个词要掌握到什么程度：有的词要会说、会写，有的词听到、读到能懂就够了。专业上这叫**主动词汇**（productive vocabulary：说和写时能用出来）和**被动词汇**（receptive vocabulary：听和读时能理解）。听、说、读、写四项是这两类再按“口头 / 书面”拆分：

|  | 口头 | 书面 |
|---|---|---|
| 被动（理解） | 听 | 读 |
| 主动（使用） | 说 | 写 |

现在没有这类数据。相关的只有：按“词 + 词性”的 CEFR 等级（`lemma_cefr`，CEFR-J 与 Octanove，9,988 条）、词频（wordfreq）、义项的 common / extra 分级、义项的语域与地域标签。它们都不能直接回答“这个词要不要会用”。

## 2. 目标

- 每个词条按词性，分两档标出它是主动词汇还是被动词汇：**母语者**一档，**高级二语学习者**一档。
- 单词词条和短语词条都覆盖。
- 听说读写的细分由服务端算好返回，不额外产出。
- 和其他事实一样走产出、审核、发布，可追溯、可纠正。

## 3. 数据模型

### 3.1 新事实类型 `vocabulary`

| 项 | 内容 |
|---|---|
| 挂在 | 词条（entry） |
| 数量 | 每个词性一条（与翻译“每种语言一条”同理，按词性占一个格） |
| 内容 | `{ pos, native, learner }`，`native` 和 `learner` 各为 `active`（主动）或 `passive`（被动） |
| 内容键 | `pos`、`native`、`learner` |
| 写入规则 | `native` 为 `passive` 时 `learner` 必须也是 `passive`（学习者的主动词汇是母语者主动词汇的一部分），否则 `422` |
| 审核 | Jev 每档一问，两问都过阈值即定；不过的交审核模型判断整条 |

- `pos` 必须是该词条某个 **common** 义项的词性；词条有几个 common 义项的词性，就有几个格。
- 只对 common 义项生效。**extra 义项（罕见、专业、过时）两档一律视为被动**，不单独标，也不占格。
- 短语词条的义项通常只有一个词性，所以一般只有一条。
- 两档放在同一条事实里一起产出、一起审核，便于拦住前后矛盾的判断。

### 3.2 判断标准（2026-11-14 确认）

**母语者（`native`）**

- 主动：母语者在日常说话或写作中会自己用出这个词（这个词性）。
- 被动：母语者听到或读到能懂，但自己很少说出或写出，例如古旧词、文学用语、领域之外的专业术语。

**高级二语学习者（`learner`）**：CEFR C1 左右，能用英语学习、工作和日常交流（约相当于雅思 7 分以上）。

- 主动：这样的学习者需要自己会用，包括常用词、学术与职场词汇、常用短语动词、常用习语。
- 被动：认识即可，包括俚语、偏门或强烈口语化的习语、地域性说法（只在英式或美式里通用的口语词），以及母语者也只是被动的词。

给模型和审核的例子（对齐用，正式规则写进 `fact-kinds.ts`）：

| 词 | 母语者 | 高级二语学习者 | 说明 |
|---|---|---|---|
| house（n.）、eat（v.）、give up | 主动 | 主动 | 基础词与常用短语动词 |
| nevertheless（adv.） | 主动 | 主动 | 书面语常用，写作要会用 |
| present（v. 呈现、颁发） | 主动 | 主动 | 偏正式，学术与职场常用 |
| a piece of cake | 主动 | 主动 | 口语常用习语 |
| kick the bucket | 主动 | 被动 | 习语偏口语且带调侃，学习者认识即可 |
| gobsmacked、knackered | 主动 | 被动 | 英式口语俚语 |
| henceforth、ere、betwixt | 被动 | 被动 | 古旧或文学用语 |
| red shift、marshalling yard | 被动 | 被动 | 领域外的专业术语 |

参考信息一并给到产出方与审核方：词频、该词性 common 义项的释义与语域、地域标签。CEFR 等级只作背景，不作标准。

### 3.3 听说读写的细分（服务端算好后返回，不产出）

两档各自由 `active` / `passive` 与该词性 common 义项的语域标签算出，作为派生字段返回，不存成事实：

| 档位取值 | 语域偏口语（informal、slang、spoken） | 语域偏书面（formal、literary） | 无明显倾向 |
|---|---|---|---|
| active | 听、说 | 读、写 | 听、说、读、写 |
| passive | 听 | 读 | 听、读 |

## 4. 工作项

- 新工作类型 `vocabulary`，放在第 4 阶段（用法），依赖义项清单已发布（要知道有哪些 common 义项的词性）。
- 属于必做的格（core）：每个词条的每个 common 词性都要有一条，计入完成度。
- 单词词条先做：8,705 个词条，约一万条事实。
- 短语词条跟随短语生产一起做，不单独再跑。

## 5. 公开接口

词条按词性返回：

```json
"vocabulary": [
  {
    "pos": "verb",
    "native": { "use": "active", "skills": ["listen", "speak", "read", "write"] },
    "learner": { "use": "passive", "skills": ["listen", "read"] }
  }
]
```

- `use` 是主动（`active`）或被动（`passive`），界面上叫“主动 / 被动”。
- `skills` 是服务端按 3.3 算好的细分，取值为 `listen`、`speak`、`read`、`write` 的子集。
- extra 义项不返回此项（两档默认被动）。

## 6. 实现范围

1. 服务端：`shared/facts.ts` 增加数据格式；`server/domain/fact-kinds.ts` 登记类型（主体、数量、内容键、写入规则、审核规则）；工作项规则与阶段；完成度计入；公开视图与接口；同步 `docs/design.md`、`spec/*.feature` 与测试，`pnpm verify` 通过。
2. 生产端：新增 `vocabulary` 工作模板，给出与审核相同的判断标准和例子。
3. 存量：不需要迁移，新增的格会在下一次重算时为每个词条打开，由 worker 产出。
4. 上线后先抽样审一批（如 A1 和 C1 各 100 条），确认两档判断稳定再放量。

## 7. 已确认（2026-11-14）

1. 分两档：母语者、高级二语学习者；高级二语学习者按 CEFR C1 定。
2. 叫法为“主动 / 被动”。
3. 接口两档都返回主动 / 被动，并各自带算好的听说读写细分。

## 8. 不在本次范围

- 更多档位（例如中级学习者 B1–B2）。
- 按义项单独标主动 / 被动（extra 义项统一视为被动，common 义项跟随词条的词性）。
- 考试词表标签（之前已决定暂缓）。
- 语法事实（仍暂停）。
