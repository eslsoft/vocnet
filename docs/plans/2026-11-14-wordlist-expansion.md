# 词表扩充（记录，2026-11-14，未开始）

## 1. 现状

- 单词词条 8,705 个，来源是 CEFR 词表（CEFR-J 与 Octanove，覆盖 A1–C2，8,855 个原形）。
- 只按 CEFR 词表收词，不在词表里的常用词没有收。

## 2. 规模估算

做法：本地词频表 `word_frequency`（wordfreq，313,560 个词形）的每个词形用 LemmInflect 还原成原形，再只保留 WordNet 收录的单词原形，按原形里最常见词形的 zipf 计数。

| zipf 门槛 | 原形数（原始） | 去噪后估计 | 已收 |
|---|---|---|---|
| ≥ 4.0 | 5,049 | 约 4,000 | 3,878 |
| ≥ 3.0 | 16,835 | 约 1.3–1.4 万 | 7,023 |
| ≥ 2.5 | 26,097 | 约 2.0–2.1 万 | 7,739 |
| ≥ 2.0 | 35,530 | 约 2.8–3.0 万 | 8,023 |
| ≥ 1.5 | 44,736 | 约 3.5–3.8 万 | 8,135 |
| ≥ 1.0 | 53,142 | 约 4.2–4.5 万 | 8,174 |

- 原始结果混有约 20%–25% 噪音：人名地名（john、london、china）、字母缩写（s、uk）、WordNet 单独收录的词形（going、felt、saying）。
- WordNet 不收冠词、介词、代词，这些已有，影响很小。
- 结论：母语者认识的常用词（zipf 约 1.5–2.0）约 3 万–3.8 万个原形，与 Brysbaert 等（2016）“20 岁母语者认识约 4.2 万原形”同一量级；比现在多 2 万–3 万。

## 3. 高频漏收

zipf ≥ 4.0 的原形里有约 1,171 个不在库中，去噪后仍有一批真正的常用词，例如 portfolio、vacuum、premium、authentic、ethics、funding、layout、warfare、sibling、theoretical、brutal、defensive。它们不在 CEFR 词表里，应最先补。

## 4. 下一步（待启动）

1. **建导入词表**：从词频表还原原形，用 WordNet（单词、非专名）过滤，去掉人名地名、字母缩写、未还原的词形，参照 Brysbaert 6.2 万原形词表校准；按 zipf 排优先级。
2. **导入前给 owner 看**：各频段数量与抽样，确认门槛（建议先到 zipf ≥ 3.0，再逐步放到 2.0 或 1.5）。
3. **分批导入**：先补 zipf ≥ 4.0 的高频漏收，再按频段由高到低分批；复用现有导入过滤（重复与拼写变体）和批次排队。
4. **生产量**：单词词条增加数倍，每个词条一整套事实；短语随之增加（罕见词短语少，预计再增 2 万–4 万）。按批次观察审核吞吐再决定节奏。
